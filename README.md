# JobTrack

A full-stack job application tracker built with React, Vite, Node.js, and Express.

## Features
- Dashboard with application statistics
- Add and manage job applications
- Update application statuses
- Search and filter applications
- Browser-based data persistence using localStorage

## Tech Stack
- **Frontend:** React, Vite
- **Backend:** Node.js, Express
- **Storage:** localStorage (database integration planned)

## Getting Started
Clone the repository and install dependencies in the frontend and backend folders.

Run each application using its respective npm scripts.
